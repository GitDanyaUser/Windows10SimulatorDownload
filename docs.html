Win10Sim.Sdk Namespace

Reference • Target Framework: .NET / WPF • Assembly: Win10Sim.Sdk.dll

The Win10Sim.Sdk namespace contains the complete public API surface exposed to third-party applications ("mods") running inside Windows 10 Simulator.

When an app is compiled in Apps Manager, the compiler is given a sandboxed reference assembly containing only the types defined in Win10Sim.Sdk. Internal simulator subsystems—such as host windows, the virtual file system (VFS), and system settings—are invisible to app code and accessed exclusively through runtime implementations provided to your app.

 Sandbox Isolation

Apps cannot directly reference simulator internals. All interactions with user files, desktop notifications, XAML UI loading, and persisted settings must go through the IModContext instance passed to ModApp.CreateView(IModContext).

Types in Win10Sim.Sdk

Type Kind Description
ModApp Class Abstract base class that serves as the entry point for every simulator app.
IModContext Interface Provides access to simulator services, virtual storage, UI loading, dialogs, timers, and notifications.
IModFiles Interface Provides file and directory operations on the simulator's virtual drive (C:\...).
IModSettings Interface Reads user-configured values from Settings.json and notifies of live changes.
IModWindow Interface Represents the desktop window hosting the app's UI, menu bar, and optional ribbon.
IModClipboard Interface Provides read and write access to the system text clipboard.
IModRibbon Interface Configures tabs, Quick Access buttons, the File menu, and help button on ribbon windows.
ModMenuItem Class Represents an entry or separator in a menu bar, context menu, drop-down button, or ribbon File menu.
ModRibbonTab Class Represents a standard or contextual tab inside an IModRibbon.
ModRibbonGroup Class A titled container of large or stacked buttons inside a ModRibbonTab.
ModRibbonButton Class A ribbon command button supporting icons, glyphs, toggles, checkboxes, and drop-down menus.
ModInfo Class Exposes read-only metadata and granted permissions from AppInfo.json.
ModPermissionException Exception Thrown when an app invokes a restricted API without the required permission in AppInfo.json.

Template App Files

Every Windows 10 Simulator app bundle is built from four standard template files: App.cs, MainView.xaml, AppInfo.json, and Settings.json. Use these official starter templates when creating a new app in Apps Manager.

 XAML Constraints

Use plain WPF markup only with the two standard XML namespaces. Custom controls (clr-namespace), inline event attributes (such as Click="..."), and Source / NavigateUri attributes are not supported. Assign an x:Name to elements and hook events or load images in App.cs using context.Find<T> and context.LoadImage.

App.cs

The advanced C# entry point showing ribbon configuration, Quick Access buttons, dialog prompts, UI timers, and live settings.

C# — App.cs 
using System;
using System.Collections.Generic;
using System.Linq;
using System.Windows;
using System.Windows.Controls;
using Win10Sim.Sdk;

namespace TemplateApp
{
    // This is the app. Keep one class that derives from ModApp (or set "entryClass" in AppInfo.json).
    // The simulator creates it when the app is started from Start, the taskbar or Command Prompt.
    public class App : ModApp
    {
        private int _clicks;
        private TextBlock? _counter;
        private TextBox? _editorBox;
        private TextBlock? _statusText;
        private IDisposable? _timer;
        private bool _isAutoClickerActive;

        public override FrameworkElement CreateView(IModContext context)
        {
            // Loads MainView.xaml from this folder. Hook events here (x:Name + Find), not in the XAML.
            FrameworkElement view = context.LoadXaml("MainView.xaml");

            TextBlock greeting = context.Find<TextBlock>(view, "GreetingText")!;
            Button button = context.Find<Button>(view, "ClickButton")!;
            _editorBox = context.Find<TextBox>(view, "EditorBox");
            _statusText = context.Find<TextBlock>(view, "StatusText");
            _counter = context.Find<TextBlock>(view, "CounterText");

            // Values from Settings.json: the user edits them in Apps Manager.
            ApplySettings(context, greeting);
            context.Settings.Changed += key => ApplySettings(context, greeting);

            // The Data folder belongs to this app alone (no permission needed). Relative paths start there.
            if (context.Data.Exists("clicks.txt"))
                int.TryParse(context.Data.ReadText("clicks.txt"), out _clicks);
            UpdateCounter();

            if (context.Window.Ribbon is { } ribbon)
            {
                var saveBtn = new ModRibbonButton("Save", () => {
                    context.Data.WriteText("notes.txt", _editorBox?.Text ?? "");
                    SetStatus("Saved via Ribbon.");
                }) { Glyph = "\uE74E", ToolTip = "Save (Ctrl+S)" };

                var autoClickerBtn = new ModRibbonButton("Auto-Clicker", () => {
                    _isAutoClickerActive = !_isAutoClickerActive;
                    SetStatus(_isAutoClickerActive ? "Auto-clicker running..." : "Auto-clicker paused.");
                }) { Glyph = "\uE916", IsToggle = true, ToolTip = "Toggle background counter ticker" };

                var homeTab = new ModRibbonTab("Home");
                homeTab.AddGroup("Actions")
                    .AddLarge(new ModRibbonButton("Prompt", () => {
                        context.Prompt("User Input", "Enter your name:", "Guest", name => {
                            if (!string.IsNullOrEmpty(name)) greeting.Text = "Hello, " + name + "!";
                        });
                    }) { Glyph = "\uE8AC" })
                    .AddStack(
                        autoClickerBtn,
                        new ModRibbonButton("Confirm", () => {
                            context.Confirm("Confirmation", "Reset click counter?", confirmed => {
                                if (confirmed) { _clicks = 0; UpdateCounter(); }
                            });
                        }) { Glyph = "\uE787" },
                        new ModRibbonButton("Picker", () => {
                            context.PickFile(false, @"C:\Users\User\Documents", "", path => {
                                if (path != null && context.Info.Permissions.Contains("files"))
                                    SetStatus("Picked file: " + path);
                            });
                        }) { Glyph = "\uE8E5" }
                    );

                var toolsTab = new ModRibbonTab("Tools") { ContextTitle = "Advanced Tools", ContextColor = "#0078D7" };
                toolsTab.AddGroup("Logger")
                    .AddLarge(new ModRibbonButton("Log Info", () => {
                        context.Log("User logged info at " + DateTime.Now);
                        context.Notify("Template App", "Timestamp logged to Apps Manager.");
                    }) { Glyph = "\uE946" });

                ribbon.SetTabs(new[] { homeTab, toolsTab });
                ribbon.AddQuickAccessButton(saveBtn);
                ribbon.SetFileMenu(new[] {
                    new ModMenuItem("Settings Info", () => context.ShowMessage("Settings", "Current greeting: " + context.Settings.GetString("greeting"))),
                    ModMenuItem.Separator(),
                    new ModMenuItem("Exit App", () => context.Window.Close())
                });
                ribbon.SetHelp(() => context.ShowMessage("Help", "Explore the ribbon tabs above!"));
            }

            // Hook click button
            button.Click += (s, e) =>
            {
                _clicks++;
                context.Data.WriteText("clicks.txt", _clicks.ToString());
                UpdateCounter();

                int every = Math.Max(1, context.Settings.GetInt("notifyEvery", 5));
                if (context.Settings.GetBool("notify", true) && _clicks % every == 0)
                {
                    // Needs "notifications" in "permissions" (AppInfo.json). Without it a ModPermissionException is thrown.
                    context.Notify("Template App", "You clicked the button " + _clicks + " times.");
                }
            };

            // Start a UI thread timer (ticks every second)
            _timer = context.StartTimer(TimeSpan.FromSeconds(1), () =>
            {
                if (_isAutoClickerActive)
                {
                    _clicks++;
                    UpdateCounter();
                }
            });

            // Load saved notes if they exist
            if (context.Data.Exists("notes.txt") && _editorBox != null)
            {
                _editorBox.Text = context.Data.ReadText("notes.txt");
            }

            return view;
        }

        private void ApplySettings(IModContext context, TextBlock greeting)
        {
            greeting.Text = context.Settings.GetString("greeting", "Hello!");
            greeting.FontSize = context.Settings.GetString("textSize", "Medium") switch
            {
                "Small" => 16,
                "Large" => 32,
                _ => 22
            };
        }

        private void UpdateCounter()
        {
            if (_counter != null) _counter.Text = "Clicks: " + _clicks;
        }

        private void SetStatus(string text)
        {
            if (_statusText != null) _statusText.Text = text;
        }

        public override void OnClosed()
        {
            // Clean up timer when window closes
            _timer?.Dispose();
        }
    }
}

Defines the app's identity, version 2.0.0, ribbon window activation, and advanced permissions.

  "id": "template.app",
  "name": "Template App",
  "version": "2.0.0",
  "author": "You",
  "description": "An example app with ribbon, menus, clipboard, prompts, and timers.",

  // The icon: a .png or .ico file in this folder. Without it the glyph below (Segoe MDL2 Assets) is used.
  // "icon": "icon.png",
  "glyph": "\uE71D",

  // What you type in Command Prompt to start this app. Remove the line and the app can't be started from there.
  "cmdLaunch": "templateapp",

  "tileColor": "#0078D7",

  // The class that derives from ModApp. Optional: the first one found is used.
  "entryClass": "App",

    "width": 640,
    "height": 440,
    "minWidth": 400,
    "minHeight": 300,
    "resizable": true,
    "ribbon": true

AppInfo & Settings Schema

Summary of supported properties in AppInfo.json and setting types in Settings.json.

Permissions

Changing the "permissions" array in AppInfo.json requires recompiling the app in Apps Manager before the new permissions take effect.

Permission Required By Description
"files" IModContext.Files, IModContext.PickFile Grants access to the user's virtual drive folders (C:\Users\User\...) and the Open/Save file picker. Private app storage (IModContext.Data) requires no permission.
"notifications" IModContext.Notify(string, string) Allows posting toast banners and Action Center notifications.
"clipboard" IModContext.Clipboard Grants read and write access to the system text clipboard.

Window Options ("window" in AppInfo.json)

Property Type Description
"width" / "height" number Initial dimensions of the app window in pixels.
"minWidth" / "minHeight" number Minimum allowed dimensions when resizing the window.
"resizable" boolean Determines whether the user can resize or maximize the window.
"ribbon" boolean When true, hosts the app in a File Explorer-style ribbon window and populates IModWindow.Ribbon (otherwise null).

Settings.json Field Types

Type SDK Reader Method Extra Schema Properties
"string" GetString(key, fallback) value (string)
"int" GetInt(key, fallback) value (int), min, max
"double" GetDouble(key, fallback) value (number), min, max
"bool" GetBool(key, fallback) value (boolean)
"choice" GetString(key, fallback) options (string array), value (selected string)

Core C# Patterns in Win10Sim Apps

Feature Usage in Simulator Apps Example
Namespaces & using Import Win10Sim.Sdk together with WPF namespaces (System.Windows, System.Windows.Controls, System.Windows.Media). using Win10Sim.Sdk;
Inheritance & override Your entry class inherits from ModApp and overrides CreateView (and optionally OnClosed). public class App : ModApp
Events & Lambdas Subscribe to WPF control events (button.Click += ...) and live setting updates (context.Settings.Changed += ...). btn.Click += (s, e) => { ... };
Nullable Types (?) #nullable enable is active; Find<T> and LoadImage return nullable references (T?, ImageSource?). TextBlock? tb = context.Find<TextBlock>(view, "Title");
Exception Handling Catch ModPermissionException if calling context.Files, context.PickFile, context.Clipboard, or context.Notify when permissions might be omitted. try { context.Notify(...); } catch (ModPermissionException) { }

Common C# Snippets for SDK Tasks

C# — Images, User Files, Menus & Window Control 
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;
using Win10Sim.Sdk;

// 1. Load an image from the app folder into a XAML <Image x:Name="LogoImage"/>
Image? logo = context.Find<Image>(view, "LogoImage");
ImageSource? source = context.LoadImage("assets/logo.png");
if (logo != null && source != null)
    logo.Source = source;

// 2. Read/write user documents (requires "files" permission in AppInfo.json)
try
{
    context.Files.CreateFolder(@"C:\Users\User\Documents\MyApp");
    context.Files.WriteText(@"C:\Users\User\Documents\MyApp\export.txt", "Hello User!");
}
catch (ModPermissionException ex)
{
    context.ShowMessage("Permission Required", ex.Message);
}

// 3. Update window title and status
context.Window.Title = "Document - Edited";

Simulator XAML Rules vs. Standard Desktop WPF

XAML Feature Status How to Use in Win10Sim
Standard WPF Controls & Panels Supported Grid, StackPanel, DockPanel, WrapPanel, Border, ScrollViewer, TextBlock, TextBox, Button, CheckBox, ComboBox, ListBox, Image.
x:Name Identifiers Supported Required on any element you want to read, update, or attach events to in C# via context.Find<T>(view, "Name").
Inline Event Attributes (Click="...") Not Supported XAML is parsed dynamically without code-behind compilation. Attach handlers in C# (button.Click += ...).
Source / NavigateUri Not Supported Declare <Image x:Name="MyImg"/> in XAML and assign img.Source = context.LoadImage("pic.png") in C#.
clr-namespace / Custom Controls Not Supported Stick to the default WPF presentation and x namespaces only.
